難易度。 Level 1 は TARGET = NOW の nonreduced 状態から開始。 Level 2 は TARGET と NOW が異なる状態から開始。 Level 3 はさらに大きく離れた初期状態を選び、長めの手数を要求します。

ルール。 上の TARGET と、その直下の NOW を見比べてください。 各列の数字が全部一致し、かつ reduced になればゴールです。

左端の数字 \(1,\dots,n\) が各 pipe の始点です。 同じ始点番号の pipe は盤面全体で同じ色です。

左から入った pipe \(i\) が上端の列 \(w(i)\) に出れば、現在の置換は [w(1),…,w(n)]。途中で右端へ逃げると「置換ではない」状態です。

Reduced では cross の総数が Coxeter length ℓ(w) に一致します。 赤枠の cross は、色付き pipe の同じペアが複数回交差している箇所です。
